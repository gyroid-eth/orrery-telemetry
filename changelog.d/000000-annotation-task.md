### agent の役割とタスクの説明を利用者が編集できるようにする

annotationに200字までの`task`を追加しました。Mailへ登録された元の説明を変えずに表示を上書きでき、空文字で保存すると元の説明へ戻ります。dashboardの一覧とNETWORKでも上書きを表示します。

`POST /api/annotate`は、省略した欄を維持し、明示的な空文字でだけ消す部分更新になりました。role・emoji・groupの既存の全項目送信は従来どおりです。新しい欄と更新の意味を API の利用側が識別できるよう、`GET /api/version`の互換世代を37から38へ上げました。
