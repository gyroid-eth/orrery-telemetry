# Mobile font sources

The bundled fonts remain under their accompanying SIL Open Font License 1.1 files. Fraunces normal400–600 is used for names/headings, italic600 for the existing ask/question glyph. IBM Plex Mono400/500/600 supplies observations, controls and emphasis. Reader conversation text uses IBM Plex Sans for Latin and IBM Plex Sans JP for Japanese. The browser fetches the Japanese file only when matching text is present. CSS requests no external font service.
